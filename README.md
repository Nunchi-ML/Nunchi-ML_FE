## 🎨 화면 — 노션 「화면명세서」가 정본

| 화면 ID | 화면 | 보이는 것 |
|---|---|---|
| `S-01` | 🏠 소개 | 프로젝트 한 줄 소개 · 데이터 · 예측 대상 |
| `S-02` | 📊 데이터 살펴보기 | EDA 그래프 (타깃 분포 · 주요 변수) |
| `S-03` | 🏆 모델 비교 | 모델별 검증 점수 · 최종 모델 |
| `S-04` | 🔍 중요 변수 | 변수 중요도 그래프 · 쉬운 말 설명 |
| `S-05` | 🔮 예측해 보기 | 값 입력 → 예측 · 확률 · 크게 작용한 변수 3개 |

> 발표 때는 시연하지 않고, 최종 모델 결과가 반영된 화면을 캡처해서 PPT에 넣어요.
