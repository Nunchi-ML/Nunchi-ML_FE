# 눈부심 노출 회피와 사전 인지·대응: 시뮬레이터 반영

기준: 2026-11-06 사용자 기획 정본과 후속 정정. 서비스의 목표는 이동시간·교통과 눈부심 예상 노출을 비교하고 불가피한 구간의 사전 인지·대응을 돕는 것이다. 실제 노출 감소·사고 예방 효과를 입증한 서비스로 표시하지 않는다.

## 입력과 구현 상태

두 도로 모두 같은 전 경로 관측 흐름을 사용한다. 신천대로는 밝기 전환 체험도 제공한다. 기존 사고 연구·원자료는 별도 보존하고 FE의 사고 위험 배수·안전 점수 표시는 제거했다. 시뮬레이터의 차량 간 접촉 처리는 기존 게임 물리이며 영상 객체검출을 추가한 것이 아니다.

## 미확인과 경로 비교 규칙

`src/game/preTrip.ts`는 사진 없음, 범위 밖, 진행방향 불일치, 사진 만료, 예상 도착 전 만료, 사진 시점 G 불일치, 최종 검증 전 결과를 미확인으로 남긴다. G전용·사진전용·시범 결과를 검증된 사진+G 전 경로 결과로 대체하지 않는다. G전용은 대조군이며 카메라 부재의 자동 대체정책이 아니다.

관측은 관측 당시 상태이다. 유효기간 내라도 미래 도착시 동일하다고 보장하지 않으며 화면에 이를 표시한다. 현재 차량 사진이 정상이어도 별도의 경로 관측 상태·경고는 유지한다. 체감 민감도는 선행 안내 거리에만 반영하며 사진 등급은 바꾸지 않는다.

노출 비교는 허용 추가시간·거리 안에서 통제된 후보를 제외한다. 관측이 미확인인 후보를 노출 0으로 취급하거나, 체험 속도 가정값을 실제 교통 시간으로 취급해 노출 회피를 추천하지 않는다. 충분한 비교 조건이 없으면 기본 코스와 구간 안내를 유지한다. 소통속도·혼잡을 사고 노출량 분모인 통행대수로 쓰지 않는다.

경로 조회 API·예보·교통·갈림길 정보가 없어 실제 우회 경로를 만들어 내지는 않는다. 현재 기본 코스 시간은 50 km/h 가정값이며 사용자 화면에 표시한다. 갈림길 전 우회·전광판 설치거리/각도·안내 해제 정책의 실도로 검증은 후속이다.

## 실제 입력과 가상 예시의 분리

- `src/data/roadside_feed.json`: 실제 연결용 입력. 현재 관측·대안 경로 배열은 비어 있다.
- `src/data/roadside_examples.json`: 사용자가 **안내 예시 체험**을 선택할 때만 사용한다. 가상 카메라 위치·방향·화각, 시뮬레이션 관측 시각·G와 사진 SHA-256을 기록했다.
- `public/examples/*-roadside.jpg`: 이 프로젝트의 3D 장면에서 만든 가상 사진이다. 실제 도로변 촬영 사진·학습 모델 결과·사람 정답이 아니다. 등급과 10분 유효기간은 기능 흐름 설명을 위해 수동 구성한 예시다. 실제 입력 모드에서는 허용하지 않는다.
- `src/data/route_analysis.json`: 최종 모델 결과 배열은 계속 비어 있다. 원사진 라벨을 바꾸거나 AI 참고 판정을 사람 정답으로 교체하지 않았다.
- 주행 중에는 번들 입력을 읽으며 새 지도·추론 API를 호출하지 않는다. 현재 사진 시범 API는 사용자가 앱에서 전송을 시작할 때만 동작한다.

실제 연결은 수집 권한·메타데이터·사진 갱신/실패 처리·예보 가용 시점·교통 캐시의 요청 문맥과 3D 경로 지원을 추가 확인해야 한다. 카카오 키·인증·결제·유료전환을 변경하지 않았고 호출도 추가하지 않았다. 요금은 운전자 화면에 고정하지 않는다.

## 화면과 주행 체험

메인은 도로 선택·현재 코스·출발을 먼저 보여준다. 다른 추천 코스, 날짜·날씨·음성, 관찰 속도·통과 시간, 전방 관측 연결 정보, 체험 설명은 접어서 필요할 때 연다. 출발 버튼과 현재 속도 설정은 항상 보이며, 세로 휴대폰 메인도 읽을 수 있고 지도는 별도로 크게 열 수 있다. 주행 시 가로 화면 안내는 유지한다.

기본 주행은 **자유 주행**이다. 새 코스 선택·사진 예시 코스 이동 시에도 관찰 상한을 자동 적용하지 않는다. 사용자가 40/60/80 km/h를 직접 선택한 경우에만 상한이 적용되며, 메인 하단의 해제 버튼이나 휴대폰 설정에서 해제할 수 있다. 입력 준비용 `referenceView.observationSpeed`/`observationKmh`는 일정 속도 비교를 위한 메타데이터이며, 실제 UI 기본값은 `defaultObservationKmh: 0`이다.

출발 전 관측 구간·미확인 길이·시간·거리·소통을 확인하고, 주행 중에는 지도와 짧은 음성으로 안내한다. 위험 경고의 중복은 기존 발화 집합·대기시간으로 억제하지만 실사용 효용을 검증한 정책으로 주장하지 않는다. `미확인`은 회색/점선으로 구분하며 위험 확정의 빨간 경고로 바꾸지 않는다.

차량 디스플레이의 큰 속도계와 핸들 뒤의 정적 계기판은 제거했다. 지도 구석의 작은 속도 표시를 사용하고 디스플레이를 약 2.4:1로 줄여 오른쪽에 배치했다. 2112×896의 2배 밀도 내비 캔버스·다중샘플·모바일 해상도 상향을 적용했다. 출구 연출은 도로 시야에 집중해 내비 글자에 전역 블러를 걸지 않는다. 모바일 도착 기록은 압축하고 휴대폰은 홈부터 연다.

기존 겨울 추천 코스가 건물에 가려지는 것을 확인해 iM뱅크 4/5 18:00, 겨울 아침 12/20 08:25, 늦겨울 퇴근길 2/20 17:10으로 조정했다. iM뱅크 코스는 본점 350 m 전 출발, 본점 통과 1.0 km다.

맑음·구름·흐림은 하늘 배경과 구름량, 직사광·그림자·원거리 안개를 함께 바꾼다. 실제 기상 관측이 아닌 사용자가 선택한 체험 조건이다. 일반 모드는 가속 반응·최고속도를 높였고 낮은 프레임에서도 주행 시간이 지나치게 느려지지 않도록 조정했다. 실제 차량의 가속 성능을 재현한 수치는 아니다.

디스플레이의 기울기와 아래쪽 돌출 장식을 없애고 지도·차량 화살표·상단 문구·경고창을 같은 가로 중앙선에 맞췄다. 휴대폰 앱 이름은 전방 사진·경로 안내·연결 상태·설정으로 줄여 한 줄로 표시한다. 일반 설명은 한국어 단어 중간에서 잘리지 않도록 줄바꿈한다.

지하차도 지붕 아래에는 공간별 조명 감쇠를 적용해 낮음 그래픽에서도 내부가 어둡고 바깥 출구가 밝게 보인다. 출구 효과는 실제 통과 시간과 가장 어두웠던 장면 밝기 차이를 반영하며, 양방향·여러 속도의 연속 주행을 점검한다. 이는 측정·보정한 생리 모델이 아닌 체험 연출이다. 화면 전체의 흰색 막과 블러는 제거했다. 톤 매핑 전 HDR 빛 번짐을 태양 주변에 집중하고, 출구에서는 밝은 외부 표면과 차선이 잠시 과노출됐다 회복된다. 태양 주변의 코로나·광선을 강화하고, 출구 마지막 30 m부터 밝은 표면의 번짐을 이어 경계에서 효과가 갑자기 켜지는 느낌을 줄였다. 포털의 밝기 입력도 외부와 연속적으로 연결한다. 어두운 물체의 대비와 내비 선명도는 유지하며, 태양이 가려지거나 흐림 조건이면 직접광 번짐을 억제한다. 지면 개구부는 옹벽 두께 안에서 끝나도록 조정해 옹벽 바깥의 빈 틈을 메우고 도로 위 개방 공간은 유지한다.

전광판은 코스 초반과 지하차도 진입 전의 가상 위치를 사용한다. 실제 설치 위치가 아니며, 초반 약 70 m·지하차도 램프 전 약 80 m 등의 간격은 배치 가정이다. 내비와 같은 구간 관측을 사용해 미확인·주의·가상 예시를 구분하고, 밝기 전환은 별도 안내한다. 정적 사진을 미래 위험 확정으로 표시하지 않는다. 전광판은 동시에 가까운 두 개만 렌더링하며, 실제 도로의 읽기 시간·갈림길 전 우회·교통 운영기관 연동은 후속 검증 대상이다.

전광판의 눈부심은 전방 카메라 사진(+촬영 시점 G)을 학습한 모델로 해당 구간을 판정해 사전 안내하는 흐름이다. 학습은 오프라인, 주행 화면은 저장된 구간 판정을 사용한다. `전방 200 m · 눈부심 강함/주의/관측 없음`으로 거리와 기존 사진 등급을 함께 보존한다. 관측 없음은 해당 사진의 결과이며 이후 주의 구간을 덮지 않는다. 지하차도는 진입 전에 `전방 150 m 지하차도 · 출구 밝기 전환 부담 큼`처럼 예상 부담도 안내한다. 경로·날짜·시각·방향이 맞는 최종 밝기 전환 결과가 있으면 이를 사용하고, 없으면 기존 초안 계산의 **체험값**이라고 구분한다. 부담 작음/보통/큼의 경계 .35/.65는 UI 설명용 가정이며 검증된 의학적 기준이 아니다. 실제 모델·카메라 데이터가 아직 비어 있는 현재 상태를 학습 완료로 표시하지 않는다.

## 검증과 재현

- `npm test`: 사진/G·유효시간·방향·ETA, G전용 대체 금지, 가상/실제 모드 분리, 경로 허용 범위·통제·미확인 비교, 민감도, 출구 연출·회복·야간을 검사한다.
- `npm run prepare:routes`: 최종 추론 없이 7코스×3날씨의 추천 입력 21개를 준비한다. 기하학적 방향 점검은 건물 가림 성능이 아니다.
- 로컬 preview 실행 후 `npm run audit:scene -- http://127.0.0.1:4343`: Playwright CLI로 달구벌대로 각 코스 12지점의 실제 장면 태양·건물·차체 차폐를 검사한다. `PLAYWRIGHT_CLI`에 CLI JS 경로, `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`에 설치된 Chromium을 지정할 수 있다. CLI는 없으면 npm exec로 실행하며 앱 의존성은 추가하지 않는다.
- `src/data/course_visibility_audit.json`: 밝기 점검 기록이다. 맑음·일반 모드·스마트 유리 꺼짐의 표본 결과이며 학습 모델 성능·실제 운전자 시야 정확도나 효과 검증으로 사용하지 않는다. 건물/카메라/광학 조건을 바꾸면 다시 확인한다.

현재 범위는 태양광이다. 야간 전조등 번짐·개인 의료효과·실제 사고 감소를 평가하지 않았다.
