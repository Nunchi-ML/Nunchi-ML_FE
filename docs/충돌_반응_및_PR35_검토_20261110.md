# PR #35 검토와 일반 주행 충돌 반응 수정

## 검토 대상

- PR #35: `223ed6df99b07bf81589aa9c9eba3195f1ef258a` (기준 `8ceae35`)
- 이번 수정 기준 main: `33893bd` (사용자 안내 문구를 정리한 PR #34 포함)

PR #35가 바꾼 화면 상태와 일반 주행 충돌은 다른 경로다. `__sincheonDemo`를 켠 자동 시연에서 앞차 위치를 `Math.max`로 이동시켜 간격을 확보하며, 이 경로는 일반 충돌 처리를 거치지 않는다. 따라서 이 시연에서 접촉이 없다는 확인으로 일반 주행의 충돌 후 속도·조향을 검증할 수 없다. 해당 위치 보정은 물리적인 충돌 해석도 아니다.

PR #35는 문구 수정 전 main에서 생성돼 그 커밋의 미리보기에는 ‘모델 ③’가 남아 있다. 패치가 문구를 다시 추가한 것은 아니다. 최신 main은 주행 경고·내비게이션·전광판을 ‘지하차도 진입 · 밝기 변화 큼/보통/작음’으로 표시한다.

## 확인한 일반 주행 문제

- 측면 겹침에서 조향 목표를 접촉 반대편으로 40cm 더 옮기고 횡속도를 강제로 부여했다. 입력을 놓아도 차가 반대 방향으로 계속 움직일 수 있었다.
- 접촉이 이어지는 프레임마다 속도를 85%로 줄였다. 정면 접촉에서는 앞차 속도의 절반으로 제한해, 충돌 직후 과도하게 느려질 수 있었다.
- 충돌을 주변 차량 이동 전에 처리해, 이후 차량 이동·차간 거리 보정으로 겹침이 다시 생길 수 있었다.

이 처리는 PR #35에서 새로 추가된 코드가 아니며, 이번 수정은 일반 주행 경로에 적용한다. 자동 시연의 차량군·어둡기 곡선·조명 변경을 되돌리지 않는다.

## 수정

- 이번 프레임의 주변 차량 이동과 간격 정리가 끝난 뒤 접촉을 해소한다.
- 측면 접촉은 침투와 접촉 방향의 횡속도를 제거한다. 반대 방향의 강제 조향·반복 전진 감속을 없애고, 운전자가 벗어나는 방향의 조향은 보존한다.
- 정면 접촉은 앞차 속도에 맞추고, 후방 접촉은 뒤차 위치·속도를 정리한다. 플레이어를 앞으로 순간 이동시키지 않는다.
- 같은 차와 접촉이 이어지는 동안 충격 알림·감점을 반복하지 않는다. 새 주행에서는 접촉 이력과 충격 상태를 초기화한다.
- 주행 화면의 ‘빛 변화 안내 체험’ 버튼을 제거한다. 시작 화면에 ‘안내 미리보기’만 두고 도움말의 진입 위치를 수정한다. 이는 예시 안내의 배치 변경이며 두 모델의 실시간 공동 연결을 새로 구현한 것은 아니다.

## 검증

- 전체 테스트 111개와 TypeScript·프로덕션 빌드 통과.
- 정면·측면·후방 접촉을 양방향에서 확인하고, 10·30·60fps의 지속 접촉에서 속도가 반복해서 떨어지지 않음을 검사했다.
- 실제 엔진에서 측면 접촉 뒤 19.99m/s를 유지하고, 가속 입력 후 23.52m/s로 증가했다. 왼쪽 입력에 목표 위치와 실제 위치가 모두 반응했다.
- 실제 엔진에서 정면 접촉 뒤 앞차와 플레이어가 모두 10m/s, 중심 간격 4.62m로 정리됐고 조향 목표는 유지됐다.
- 시작 화면의 미리보기 열기·닫기, 데스크톱·모바일 가로 주행 화면의 체험 버튼 제거, 브라우저 실행 오류 없음을 확인했다.
- PR #35를 임시 병합한 상태에서도 충돌 없이 적용됐고 테스트 111개와 빌드가 통과했다. 검사 후 임시 병합을 되돌려 이번 PR에는 일반 주행 수정만 남겼다.

수치는 회귀 검사용 가상 배치이며 실제 차량의 충돌 물리·제동 성능 검증이 아니다. 원본 캡처와 엔진 수치는 로컬 `output/playwright/collision-review-*`에 보관한다.
