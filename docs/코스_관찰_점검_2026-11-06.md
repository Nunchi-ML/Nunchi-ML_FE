# 추천 코스와 밝기 전환 관찰 점검

2026-11-06 사용자 요청: 실제 도로 구간부터 개선. 실제 지하차도를 임의로 늘리거나 합치지 않았다.

## 점검 결과

기존 첫 추천인 중동교 지붕 구간은 3D 도로 기준 약 93.1 m다. 60 km/h에서는 약 5.6초여서 내부 밝기와 출구 회복을 차례로 관찰하기 짧았다. 가장 긴 침산교는 원래 좌표에서 약 191.7 m, 부드럽게 다듬은 3D 경로에서는 약 191.4 m다. 경로 보간에 따른 차이이며 입·출구를 옮긴 것이 아니다.

| 실제 지붕 구간 | 3D 지붕 길이 | 40 km/h | 60 km/h | 80 km/h |
|---|---:|---:|---:|---:|
| 침산교 | 191.4 m | 17.2초 | 11.5초 | 8.6초 |
| 중동교 | 93.1 m | 8.4초 | 5.6초 | 4.2초 |
| 희망교 | 80.3 m | 7.2초 | 4.8초 | 3.6초 |
| 대봉교 | 95.5 m | 8.6초 | 5.7초 | 4.3초 |

시간은 지붕 길이÷일정 속도의 계산값이며 램프를 포함하지 않는다. 실제 기록은 가속·제동·정지에 따라 달라진다. 긴 구간도 실제 인간의 완전한 암순응을 보장하는 시간으로 설명하지 않는다.

## 코스 반영

- 신천대로 첫 추천에 침산교 내부 관찰을 추가했다. 진입 전 약 220 m, 지붕 약 191 m, 출구 이후 약 260 m를 포함한다.
- 침산교와 중동교는 같은 날짜·시각·맑음·시간 고정, 관찰 속도 상한 40 km/h로 시작한다. 가속·제동은 직접 조작한다.
- 40/60/80 km/h 또는 자유 주행으로 비교할 수 있다. 일반 주행 성능은 낮추지 않았다. 상한을 낮출 때 부드럽게 감속하며 운전자의 더 강한 제동은 우선한다.
- 연속 지하차도는 반복되는 짧은 전환, 겨울 노을은 밝기 전환과 낮은 해의 겹침 관찰용이다. 여러 지하차도를 하나의 긴 터널로 합산하지 않는다.
- 가상 사진 예시는 기존 중동교 코스에 있으므로 사진 예시 버튼은 해당 코스로 이동한다. 침산교에 가상 모델 결과를 새로 만들지 않았다.
- 도착 기록에 게임 내 지붕 아래 체류 시간을 남긴다. 휴대폰 중단 시간은 제외하며 지붕 안에서 주행을 끝내면 부분 통과로 구분한다.
- 달구벌대로 3개와 iM뱅크 본점 포함 조건을 유지하고 실제 장면 태양·건물·차체 차폐를 재점검했다.
- 긴 침산교의 굽은 지붕 아래 조명이 직선 범위를 벗어나 한쪽 벽을 밝게 만들던 문제를 수정했다. 실제 경로를 8개 선분으로 따라가며 그늘을 적용하고, 12개 지하차도의 양쪽 벽이 그 범위에 들어가는지 검사했다.

## 머신러닝으로 확인할 수 있는 것과 없는 것

사진+G 입력을 준비하고 위치·방향·시각·유효시간·ETA가 맞을 때 내비·전광판으로 사전 안내하는 동작을 확인할 수 있다. 현재 FE의 최종 결과 배열은 비어 있다. 가상 관측 예시를 학습 모델 정확도 결과로 사용할 수 없다.

로컬 AI 후보의 `model3_candidate_20261106_final/USAGE.txt`와 `meta.json`에서 확인한 범위는 **입구**다. 사진 특징과 해 높이·전운량을 사용하며 출구·실제 순응시간·사고확률은 지원 범위가 아니다. 후보를 실행·튜닝·배포하거나 계수·원본 사진을 복사하지 않았다.

긴 통과는 시간에 따른 시야 연출 비교에 도움이 된다. 하지만 현재 입구 사진 모델 입력에 터널 길이·체류 시간이 들어가지는 않으므로 길이만으로 모델 성능을 검증하지 못한다. 모델 평가는 별도 입구 사진의 정답·장면 분리 시험으로, 출구/시간 반응은 별도 데이터·실험으로 검증해야 한다.

FE의 향후 밝기 전환 최종 결과는 진입·출구 양쪽의 검증 범위가 명시된 경우에만 통합 모델 결과로 표시한다. 입구 전용 결과를 출구 모델 판정으로 확장하지 않는다. 현재 전광판의 밝기 전환은 계속 체험값이다.

## 재현

- `npm run prepare:routes`: 7코스×3날씨, 총 21개 입력. 지붕별 길이·방향·속도별 시간을 기록하고 추론은 실행하지 않는다.
- `npm run audit:scene`: 달구벌대로 3개 코스의 실제 장면 12지점씩 재점검한다.
- `npm test`: 지붕/램프 구분, 부분 통과, 속도 상한·해제·제동, 최종 결과 검증 범위와 빈 결과 보존을 검사한다.

브라우저 연속 주행에서는 침산교를 최고 40 km/h로 통과했을 때 지붕 아래 **17.2263초**를 기록했다. 휴대폰 중단 전후 내부 시간은 모두 3.082초로 같았다. 모바일 크기 도착창은 접힌 상태 약 430×252 px였고, 기록을 펼쳐 확인할 수 있었다. 관측·추론 API 자동 호출과 WebGL/페이지 오류는 없었다. 이는 통행을 방해하는 앞차가 없는 조건의 시뮬레이션 점검이며 모델 성능 시험은 아니다.
